# etb-speedrun-bot-v2

[![CI](https://github.com/MattFor/etb-speedrun-bot-v2/actions/workflows/ci.yml/badge.svg)](https://github.com/MattFor/etb-speedrun-bot-v2/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Discord bot for the Escape the Backrooms speedrunning community.

## Usage

Members link their speedrun.com profile and the bot keeps their roles up to date.

- `/link <username>` - connect speedrun.com profile
- `/unlink` - disconnect it and remove the roles
